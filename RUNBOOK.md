# Monitoring Runbook

## Overview

This runbook explains how to investigate and respond to alerts generated by the monitoring system for the portfolio application.

The monitoring stack uses:
- Prometheus for metrics collection
- Grafana for visualization
- Alertmanager for alert handling
- cAdvisor for Docker container metrics
- Node Exporter for host metrics

---

## Alert: Service Down

### Description

This alert fires when a monitored service or container becomes unavailable.

### Investigation

1. Check the Grafana dashboard to identify which service is unavailable.
2. Check running containers:

   docker ps

3. Check the affected container's logs:

   docker logs <container_name>

4. Check Prometheus targets to confirm whether the service is reachable.

### Resolution

Restart the affected container:

   docker restart <container_name>

If necessary, redeploy the application:

   cd /root/pe-portfolio-site
   ./redeploy-site.sh

---

## Alert: High CPU Usage

### Investigation

Check the Grafana Container CPU Usage panel and identify the container consuming excessive CPU.

Check container resource usage:

   docker stats

Check its logs:

   docker logs <container_name>

### Resolution

Restart the affected container if necessary:

   docker restart <container_name>

Continue monitoring CPU usage in Grafana after the restart.

---

## Alert: High Memory Usage

### Investigation

Check the Grafana Container Memory Usage panel.

Run:

   docker stats

Identify which container is consuming excessive memory.

### Resolution

Inspect the container logs:

   docker logs <container_name>

Restart the container if necessary:

   docker restart <container_name>

Verify memory usage returns to normal in Grafana.

---

## Alert: Application Failure

If the portfolio application becomes unavailable:

1. Check container status:

   docker ps

2. Check application logs:

   docker logs myportfolio

3. Check Nginx logs:

   docker logs nginx

4. Verify the application container is reachable.

5. Restart or redeploy the application if necessary.

---

## Monitoring Dashboard

The Grafana dashboard tracks:

- Container CPU usage
- Container memory usage
- Network traffic
- Service availability
- Host resource usage

These metrics can be used to identify performance problems and determine which service is responsible.
